LazyVim Cheatsheet

Referensi lengkap keymap bawaan LazyVim — dari editing, navigasi, Neo-tree, Telescope, window management, sampai integrasi Git via LazyGit & Gitsigns. Cetak, simpan sebagai PDF, atau tempel di monitor kedua.

<leader> = tombol Spasi (Space) — default LazyVim
01

Editing, Selection & Clipboard

Manipulasi teks: select, yank/copy, cut, paste, undo/redo, comment, dan search-replace.

Aksi / FiturModeKeymapDeskripsi & Fungsi
Select AllNormalggVGPilih seluruh isi file dari baris pertama sampai terakhir.
Yank barisNormalyyCopy satu baris penuh ke register default (unnamed).
Yank selectionVisualyCopy teks yang sedang diseleksi ke register.
Yank ke system clipboardNormal/Visual"+yCopy ke clipboard sistem OS (perlu xclip/wl-clipboard atau clipboard=unnamedplus aktif).
Yank per kataNormalywYank dari posisi kursor sampai akhir kata berikutnya.
Cut karakterNormalxHapus 1 karakter di bawah kursor (fungsinya seperti Delete), tersimpan di register.
Cut / Delete barisNormalddHapus satu baris penuh sekaligus meng-cut ke register default.
Cut per kataNormaldwHapus dari kursor sampai awal kata berikutnya.
Cut sampai akhir barisNormalDHapus dari posisi kursor sampai akhir baris (setara d$).
Delete selectionVisualdHapus teks yang diseleksi, tersimpan di register.
Paste setelah kursorNormalpTempel isi register setelah kursor / di bawah baris aktif.
Paste sebelum kursorNormalPTempel isi register sebelum kursor / di atas baris aktif.
Paste dari system clipboardNormal/Insert"+p · <C-r>+Tempel dari clipboard sistem OS, di Insert mode gunakan <C-r>+.
Paste tanpa timpa registerVisualpTempel menimpa selection tanpa kehilangan isi register (LazyVim me-remap agar register lama tetap terjaga).
UndoNormaluBatalkan perubahan terakhir.
RedoNormal<C-r>Ulangi kembali perubahan yang di-undo.
Move line ke bawahNormal/Visual<A-j>Pindahkan baris aktif (atau seluruh selection) satu baris ke bawah.
Move line ke atasNormal/Visual<A-k>Pindahkan baris aktif (atau seluruh selection) satu baris ke atas.
Duplicate barisNormalyy→pYank baris lalu paste di bawahnya untuk menduplikasi baris.
Duplicate selectionVisualy→gv→pYank blok terpilih, reselect dengan gv, lalu paste untuk menduplikasi blok.
Toggle Comment barisNormalgccComment / uncomment baris aktif sesuai filetype (via Comment.nvim / mini.comment).
Toggle Comment blokVisualgcComment / uncomment seluruh baris dalam selection.
Comment baris baru di bawahNormalgcoBuat baris comment baru di bawah baris aktif lalu masuk Insert mode.
Comment baris baru di atasNormalgcOBuat baris comment baru di atas baris aktif lalu masuk Insert mode.
Visual Block / Column selectNormal<C-v>Masuk mode Visual Block untuk seleksi kolom vertikal — cocok untuk multi-cursor edit sederhana.
Search & Replace (global)Command:%s/old/new/gCari & ganti semua kemunculan teks di seluruh file.
Search & Replace (konfirmasi)Command:%s/old/new/gcSama seperti di atas, tapi meminta konfirmasi tiap penggantian.
Indent / OutdentVisual> · <Tambah / kurangi indentasi selection (tetap dalam Visual mode untuk repeat).
Increment / Decrement angkaNormal<C-a> · <C-x>Tambah / kurangi nilai angka terdekat dari kursor.
Repeat last changeNormal.Ulangi perintah edit terakhir — sangat berguna untuk edit berulang.
02

Navigasi Kursor Cepat

Berpindah posisi dalam file tanpa menyentuh mouse, sampai lompat ke definisi kode via LSP.

Aksi / FiturModeKeymapDeskripsi & Fungsi
Lompat ke baris teratasNormalggPindah kursor ke baris pertama file.
Lompat ke baris terbawahNormalGPindah kursor ke baris terakhir file.
Awal baris (non-blank)Normal^Pindah ke karakter non-kosong pertama di baris.
Awal baris (kolom 0)Normal0Pindah ke kolom paling awal baris, termasuk whitespace.
Akhir barisNormal$Pindah ke karakter terakhir baris.
Lompat ke nomor barisCommand/Normal:{n} · {n}GLoncat langsung ke baris ke-n, mis. :42 atau 42G.
Kata berikutnyaNormalwLoncat ke awal kata berikutnya.
Kata sebelumnyaNormalbLoncat mundur ke awal kata sebelumnya.
Akhir kataNormaleLoncat ke akhir kata saat ini/berikutnya.
Akhir kata sebelumnyaNormalgeLoncat mundur ke akhir kata sebelumnya.
Cari karakter di baris (maju)Normalf{x} / t{x}Lompat ke ("find") atau tepat sebelum ("till") karakter x di baris yang sama.
Ulangi pencarian karakterNormal; / ,Ulangi f/t terakhir ke arah sama (;) atau berlawanan (,).
Lompat ke pasangan bracketNormal%Loncat ke pasangan () [] {} dari posisi kursor.
Scroll setengah halamanNormal<C-d> / <C-u>Scroll turun / naik setengah layar sambil kursor ikut pindah.
Paragraf berikutnya / sebelumnyaNormal{ / }Lompat ke paragraf (blok kosong) berikutnya / sebelumnya.
Go to Definition (LSP)NormalgdLompat ke definisi simbol/fungsi/variabel di bawah kursor.
Go to References (LSP)NormalgrTampilkan semua referensi/pemakaian simbol tersebut dalam project.
Go to Implementation (LSP)NormalgILompat ke implementasi konkret dari interface/fungsi abstrak.
Go to Type Definition (LSP)NormalgyLompat ke definisi tipe data dari simbol di bawah kursor.
Go to Declaration (LSP)NormalgDLompat ke deklarasi (berbeda dari definisi, tergantung bahasa).
Hover Documentation (LSP)NormalKTampilkan dokumentasi/hover info simbol di bawah kursor.
03

File Explorer (Neo-tree) & Project

Sidebar manajemen file berbasis Neo-tree — buat, hapus, rename, sampai pindah antar project.

Aksi / FiturModeKeymapDeskripsi & Fungsi
Toggle File ExplorerNormal<leader>+eBuka / tutup sidebar Neo-tree pada root direktori project.
Explorer (root dir)Normal<leader>+feAlternatif membuka Neo-tree yang berpusat di root project (bukan cwd aktif).
Fokus ke sidebarNormal<C-h>Dari buffer aktif, pindah fokus window ke Neo-tree tanpa menutup buffer (navigasi window biasa).
Kembali ke bufferNormal<C-l>Dari Neo-tree, kembali fokus ke window editor/buffer.
Buka file / folderNeo-tree<CR> / oBuka file terpilih, atau expand/collapse folder.
Buat File BaruNeo-treeaTambah file baru — ketik nama lengkap dengan ekstensi, mis. index.js, lalu Enter.
Buat Folder BaruNeo-treeaSama seperti buat file, tapi akhiri nama dengan garis miring, mis. components/.
Hapus file/folderNeo-treedHapus item terpilih (akan meminta konfirmasi).
Rename file/folderNeo-treerGanti nama item terpilih secara inline.
Copy fileNeo-treecCopy item terpilih, siap di-paste ke lokasi lain.
Cut fileNeo-treexCut (move) item terpilih, siap di-paste ke lokasi lain.
Paste fileNeo-treepTempel file/folder yang sudah di-copy atau di-cut sebelumnya.
Buka di Vertical SplitNeo-treevBuka file terpilih dalam split vertikal baru.
Buka di Horizontal SplitNeo-treesBuka file terpilih dalam split horizontal baru.
Refresh struktur folderNeo-treeRRefresh tampilan tree — berguna setelah perubahan file dari luar Neovim.
Toggle hidden/dotfilesNeo-treeHTampilkan / sembunyikan file tersembunyi (dotfiles) seperti .env, .git.
Copy path ke clipboardNeo-treeyCopy path absolut/relatif file terpilih ke clipboard.
Tutup Neo-treeNeo-treeqTutup window Neo-tree.
Switch / Buka ProjectNormal<leader>+fpBuka picker daftar project sebelumnya untuk berpindah workspace (via plugin projects/project.nvim).

Cari di file saat iniNormal<leader>+sbFuzzy search baris teks hanya di buffer aktif.
Cari Help / DokumentasiNormal<leader>+shCari topik pada help-doc Neovim/plugin.
Cari Daftar KeymapNormal<leader>+skBrowse seluruh keymap yang terdaftar saat ini.
Resume Pencarian TerakhirNormal<leader>+srLanjutkan/buka kembali sesi picker Telescope terakhir.

Integrasi Git (LazyGit & Gitsigns)

Version control tanpa keluar dari editor — UI penuh via LazyGit dan indikator perubahan baris via Gitsigns.

Aksi / FiturModeKeymapDeskripsi & Fungsi
Buka LazyGit UINormal<leader>+ggBuka antarmuka LazyGit penuh (floating terminal) di dalam Neovim.
Git StatusNormal<leader>+gsTampilkan status Git (file yang berubah/staged) melalui picker.
Git Blame (baris aktif)Normal<leader>+gbTampilkan info commit/author terakhir untuk baris tempat kursor berada.
Hunk berikutnyaNormal]hLompat ke blok perubahan (hunk) Git berikutnya di buffer.
Hunk sebelumnyaNormal[hLompat ke blok perubahan (hunk) Git sebelumnya di buffer.
Preview HunkNormal<leader>+ghpTampilkan popup diff untuk hunk di posisi kursor.
Stage HunkNormal/Visual<leader>+ghsStage perubahan hunk di posisi kursor (atau seluruh selection).
Reset / Undo HunkNormal<leader>+ghrBuang (revert) perubahan pada hunk di posisi kursor, kembali ke versi terakhir commit.
Unstage HunkNormal<leader>+ghuBatalkan staging pada hunk yang sudah di-stage sebelumnya.
Blame Line (full popup)Normal<leader>+ghbTampilkan popup blame lengkap (commit message, author, tanggal) untuk baris aktif.
Diff This (file)Normal<leader>+ghdBuka diff split antara versi file saat ini dengan HEAD.
07

System, Save & Exit

Perintah dasar sistem: simpan, keluar, dan manajemen plugin/LSP.

Aksi / FiturModeKeymapDeskripsi & Fungsi
Simpan FileNormal/Insert<C-s> · :wSimpan buffer aktif ke disk. <C-s> juga berfungsi di Insert mode tanpa keluar mode.
Keluar (Quit All)Normal<leader>+qq · :qaKeluar dari seluruh Neovim; akan menolak jika ada perubahan belum disimpan.
Keluar Paksa (buang perubahan)Command:qa!Keluar dari seluruh Neovim tanpa menyimpan, membuang semua perubahan.
Simpan lalu KeluarCommand:wqaSimpan semua buffer yang berubah, lalu keluar sepenuhnya.
Buka Lazy Plugin ManagerNormal<leader>+lBuka UI lazy.nvim untuk install/update/hapus/cek status plugin.
Buka Mason (LSP/Formatter Manager)Normal<leader>+cmBuka UI Mason untuk install/uninstall LSP server, formatter, dan linter.
Cek Kesehatan NeovimCommand:checkhealthDiagnostik menyeluruh konfigurasi, dependency, dan plugin Neovim.
Format Buffer (LSP)Normal<leader>+cfJalankan formatter (via conform.nvim/LSP) pada seluruh buffer aktif.
Catatan: <leader>w pada LazyVim default adalah grup "Windows" (lihat Kategori 05), bukan shortcut Save — sehingga Save menggunakan <C-s> atau :w secara default.
Dibuat untuk workflow LazyVim — kombinasikan dengan :Tutor dan <leader>sk untuk eksplorasi keymap lebih lanjut.
